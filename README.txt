STEVIE G'S — CHROMEBOOK EASY UPLOAD

Upload these 8 files directly to the ROOT of your GitHub repository:
- index.html
- styles.css
- script.js
- stevie-gs-logo.jpg
- site.json
- menu.json
- editor.html
- README.txt

The editor can later create an `uploads` folder automatically when photos are added.

https://steviegscoffeecompany.netlify.app/editor.html
